Comment lire cette pageToutes les commandes qui ont construit le labo, de A à Z, puis celles qui prouvent qu’il fonctionne. Chaque bloc indique la machine où il s’exécute. Aucun secret n’apparaît : chaque saisie sensible se fait à une invite masquée.

Commandes de construction, de A à Z

Ce livret rassemble les commandes qui ont construit le labo, dans l'ordre où je les ai passées, de l'hôte jusqu'au dernier service. Le jury m'a conseillé de les réunir : elles permettent à un autre administrateur de reconstruire l'infrastructure sans avoir suivi le projet. Les étapes faites dans une interface web sont données sous forme de chemin de menus.

Où taper. Chaque bloc indique la machine : HV01 (terminal de l'hyperviseur), pfSense (interface web ou console, option 8), DC (PowerShell administrateur, par SSH depuis HV01), lnx-dc01, TrueNAS (System → Shell), fedora (ssh ais@10.10.10.30), SIEM (ssh ais@10.10.10.40), wg-client (console série de Cockpit).

Trois règles tenues tout au long. Un instantané avant chaque changement. Aucun secret dans une commande ni dans un fichier : toutes les saisies sensibles sont masquées (Read-Host -AsSecureString, invites interactives). Un mot entre chevrons (<vm>, <UUID>) est à remplacer.

Commandes de test (preuve de fonctionnement)
