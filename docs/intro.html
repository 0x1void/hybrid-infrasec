Notice and summary

The setting. This report presents a project I carried out during my training as a secure infrastructure administrator. The company INFRASEC is fictitious. It gives me a client, a need and realistic constraints. The infrastructure itself is real: I built it, ran it and secured it myself, in a virtual lab. Every measurement, capture, log and incident in this report is real.

What this document does not contain. All addresses are private addresses (RFC 1918). No password, no private key, no public IP address and no personal data appears in this report. Only public keys may be quoted. In the technical annexes, admin is my administrator ID. Every document is sealed with a SHA- 256 hash (Annex P).

How to read it. The report follows the plan required by the assessment guidelines: skills, requirements, project management, choice of solutions, implementation, stakeholders, summary. Chapter 6 covers monitoring and cybersecurity. The CCP1 part, right after chapter 1, describes the foundation. The full documents are in the annexes, at the end of the report. The format. The report is written in a simple style, with this English block, guard pages and clickable contents. The acceptance test of October 11, 2026 is described in report PV-04 (Annex O).

The full title. This report takes the project report presented for CCP2 and CCP3 and adds, in French and in English, the CCP1 part: the foundation administered and secured in the first stage. It brings together the three certificates of the title.

Introduction: the project

The company and the service

INFRASEC is a small service company. About ten employees regularly work remotely. Its information system is small but complete: a firewall that is the only way in, an Active Directory domain, a file server, a monitoring platform and a SIEM. The IT team is one secure infrastructure administrator. That is my role in this project, reporting to the CISO for security decisions.

Where the project comes from

The project came in two stages. In the first stage, I built and secured the internal foundation: virtualization, segmentation, directory, storage, hardening. That stage matches the certificate “Administer and secure infrastructures”, which I passed. The CCP1 part of this report describes that first stage. The rest covers the second stage: evolving that foundation to meet a new need, and managing the security of the whole system over time.

The need came with remote work. Employees must open the file share from home, and the administrator must be able to work on the infrastructure while traveling. The easy answer would have been to open a service to the Internet. I did not choose it, because it would break the whole security model of the foundation. So the project is to design, cost, deploy and secure Zero-Trust remote access, and then to show that the security of the infrastructure is measured, managed and able to react to an incident.
